# 3단계: 프로젝트화

## 목적

- 2단계 단일 HTML을 React 프로젝트로 옮긴다.
- git(GitHub)에 올려 GitHub Pages로 배포한다. 로컬 개발 서버는 같은 Wi-Fi 안에서만 접속되므로, 다른 네트워크(모바일 데이터 등)에서 테스트하려면 외부 배포가 필요하다.

## 구성

- 프레임워크: React 19 + TypeScript
- 빌드 도구: Vite
- 시그널링: Supabase Realtime (supabase-js), 1·2단계와 같은 채널 `lobby`와 같은 신호 형식
- 공인 주소 확인: 외부 공개 STUN (`stun:stun.l.google.com:19302`)
- 배포: **GitHub 저장소에 push → GitHub Actions로 빌드 → GitHub Pages**
- Backend 없음 (정적 파일만 배포)

## 배포

- 저장소: https://github.com/kwonhee1/udp-punch (공개, main 브랜치)
- main에 push하면 GitHub Actions가 `web/`을 빌드해 GitHub Pages에 올린다.
- 주소: https://kwonhee1.github.io/udp-punch/
- Supabase 설정값(`SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`)은 `.env`를 올리지 않고 저장소 Actions 변수로 넣는다. 둘 다 공개용 값이다.
- GitHub Pages 무료 사용은 공개 저장소가 필요하다.

## 파일

```
udp/
├── 기능명세.md
├── .env                     Supabase 설정값 (git 제외)
├── .env.example
├── .github/workflows/deploy.yml   GitHub Pages 배포
├── 단계/
│   ├── 단계 명세.md
│   ├── 1단계.md
│   ├── 2단계.md
│   └── 3단계.md             이 문서
└── web/                     React 프로젝트
    ├── index.html
    ├── package.json
    ├── vite.config.ts        루트 .env에서 Supabase 값 두 개만 읽어 번들에 넣음
    └── src/
        ├── lib/              펀칭 코어 (React에 의존하지 않음, 4단계 라이브러리화 대상)
        │   ├── punch.ts          RTCPeerConnection, 후보 필터, ping/pong, 공인 IP 확인
        │   ├── peer-manager.ts   로비 목록·시그널링, 상대별 연결 상태, 같은 IP면 host 후보 유지
        │   └── identity.ts       id, 랜덤 이름, 기기 표시
        ├── hooks/usePeerManager.ts   lib 상태를 React 화면에 연결
        ├── components/       MeCard, PeerList, LogPanel
        └── App.tsx, main.tsx, styles.css
```

- 1·2단계 단일 HTML(`web/standalone.html`, `web/standalone-2.html`)은 지우고 git 태그 `2단계`에 남겼다.

## 실행

```sh
cd web
npm install
npm run dev       # 개발 서버 (같은 Wi-Fi에서 접속 가능)
npm run build     # dist/ 생성
npm run preview   # 빌드 결과 확인
```

## 완료 기준

- React 버전이 같은 브라우저 두 탭에서 연결된다 (2단계와 같은 결과).
- GitHub Pages 주소로 접속해 PC Wi-Fi ↔ 휴대폰 모바일 데이터가 srflx로 연결된다 (1단계와 같은 결과).

## 진행 상황

| 항목 | 상태 |
|---|---|
| React 프로젝트 | 완료 |
| 로컬 테스트: React ↔ React 같은 브라우저 두 탭 | 성공, `host ↔ host`, 왕복 1.8ms |
| 로컬 테스트: React ↔ 배포된 2단계 단일 HTML | 성공, `host ↔ host`, 왕복 3.0ms (신호 형식 호환) |
| GitHub 저장소 생성·push | 완료 (`kwonhee1/udp-punch`, 공개) |
| GitHub Pages 배포 | 완료 (Actions 변수 등록, Pages 소스 GitHub Actions, 첫 배포 성공) |
| 배포 주소 테스트: 같은 브라우저 두 탭 | 성공, `host ↔ host`, 왕복 1.7ms |
| 다른 네트워크 테스트 (PC Wi-Fi ↔ 휴대폰 모바일 데이터) | 대기 (휴대폰으로 확인 필요) |
